# Security and responsible publication

This repository contains analysis notes only, and cannot flash or control a Wii. Please **do not upload** raw NAND backups, IOS contents (encrypted or decrypted), console keys/certificates, serial numbers, cloud access tokens, Wi-Fi passwords, router configurations, personally identifying IP addresses, or proprietary asset dumps.

No downloaded IR script, firmware update, GPIO ownership patch or standby-mode fan modification is certified for deployment. Published observations are scoped to particular test conditions; do not test pin shorts, power rail bridging or prolonged fanless busy loops.

For research corrections, an issue with redacted code snippets, public documentation links and software version numbers is sufficient.
